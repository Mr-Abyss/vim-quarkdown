# Vim-quarkdown: Unofficial vim extension for quarkdown

## Design Philosophy

For those of you who stuck with vim, but want a bit of quarkdown convenience.

## Roadmap

### Phase 1

[] simple syntax highlighting
[] In-file Toc (ref. vim-markdown project)
[] compiling

### Phase 2

[] advanced syntax highlighting
[] advanced motions
[] advanced mappings (ref. vimtex project)

### What Will Not Be Implemented (presumebably)

These functionalities can be outsourced to other, more professional plugins.

[x] linting and syntax checking
  * [ale](https://github.com/w0rp/ale)
  * [neomake](https://github.com/neomake/neomake)
  * [syntastic](https://github.com/vim-syntastic/syntastic)

[x] Snippets and templates

  * [UltiSnips](https://github.com/SirVer/ultisnips)
  * [neosnippet](https://github.com/Shougo/neosnippet.vim)

[x] Tag navigation

  * [vim-gutentags](https://github.com/ludovicchabant/vim-gutentags)
